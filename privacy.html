PERSONAL MAILBOX UTILITY

Privacy policy

This policy describes the personal Gmail Mailbox Organization script maintained by the account owner, nchiker.

Google account data used

With the owner’s authorization, the script reads Gmail message and conversation identifiers, timestamps, labels, headers, sender and subject information, and text bodies. It uses this information to determine age, mailing-list status, protected content, and archive eligibility. It also reads and manages organizational labels and filters.

Use and storage

Routine processing runs in Google Apps Script and calls Google’s Gmail API. The script applies labels and, only after owner approval, removes the Inbox label from eligible messages. It contains no sending, message deletion, or mark-as-read action.

Script Properties store scan progress, pending message or conversation identifiers, preview identifiers and history versions, and test status. Preview approval expires after 24 hours in the script; temporary state is overwritten or removed as processing continues. Preview execution logs can contain senders, subjects, dates, identifiers, exclusion counts, and errors. Logs are stored in Google’s infrastructure under its applicable retention settings and can outlast a preview.

Sharing

The recurring script does not transmit mailbox data to GitHub, advertising services, or an AI service. Its mailbox processing and state stay within the owner’s Google account and Google’s supporting infrastructure. The owner can separately choose to inspect or share information during setup or support.

Google account data is not sold or used for advertising. The script’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Website visitors

These informational pages contain no analytics scripts, forms, cookies set by this site, or Google sign-in integration. GitHub Pages hosts the pages and may process request metadata under the GitHub Privacy Statement. Visiting these pages does not grant access to a Gmail account.

Control and contact

The owner can disable or remove the Apps Script trigger, revoke the script’s permissions in Google Account connections, and remove the script and its stored state. Archived messages remain accessible in Gmail All Mail. Questions about this personal utility can be directed through the maintainer’s GitHub profile.
